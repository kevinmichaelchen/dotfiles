# Herdr plugins from our skills

A visual proposal grounded in [the Herdr research](herdr-research.md). Cyan marks existing ingredients; rose marks proposed workflows; dashed outlines mark later options.

![A workbench built from skills](./01-portfolio.webp)

Build domain workflows around the adopted foundation. These concepts are proposed; the skill repositories supply reusable ingredients, not completed plugins.

![CI Investigator](./02-ci.webp)

Start here. Cached collectors and offline analyzers already exist. A thin adapter can expose run selection, evidence browsing, affected-set replay, and dependency counterfactuals.

![Aspira Operations](./03-operations.webp)

Keep this distribution private. Unite existing telemetry recipes behind explicit scope selection and an evidence packet; preserve their read-only contracts.

![Electric Monks](./04-monks.webp)

The most distinctive experiment: independent agent conversations, a shared briefing, and a user-selected candidate palette. Save handoffs to files instead of inferring completion from screen status.

![Ticket & Review Desk](./05-ticket.webp)

Adapt Kyle’s ticket and review workflows to native Herdr agents. Reuse Projects, Reviewr, and Annotate. Resolve missing advisor definitions and personal harness dependencies before packaging.

![Artifact Workshop](./06-artifacts.webp)

Make source, validation, preview, and feedback discoverable. Open visual previews externally. Add narrated video only after the diagram, chart, and HTML workflow earns adoption.

![Shipping & Ownership](./07-shipping.webp)

Separate shipping trends from contribution context. Both benefit from cached evidence, disclosed coverage, and reproducible reports. Neither is a measure of individual quality.

![Package the workflow, preserve the boundary](./08-packaging.webp)

Keep canonical portable skills, private Aspira overlays, and workstation installation policy distinct. Preserve specs, dependency evidence, tests, and upstream notices. Resolve duplicate installed names.

![Earn the next plugin](./09-roadmap.webp)

Ship one useful slice, validate it against the installed Herdr pin, then expand. The sequence is a proposal, not a commitment to install the entire set.

Sources: [personal skill inventory](https://github.com/kevinmichaelchen/skills), [Aspira skill inventory](https://github.com/AspiraVentures/skills), [Herdr plugin interface](https://herdr.dev/docs/plugins/). All nine diagrams were authored in Eraser, validated without warnings, rendered, and visually inspected. No plugin was installed or exercised for this proposal.
